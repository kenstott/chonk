# Support

- **Questions and usage help:** open a GitHub issue at
  <https://github.com/kenstott/chonk/issues> with the `question` label.
- **Bug reports and feature requests:** see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security issues:** email kennethstott@gmail.com instead of opening a public
  issue.

## Supported versions

Only the latest release on PyPI receives fixes. Python 3.11 through 3.14 are
supported.

## Response times

The project has a single maintainer, so support is best-effort. Issues are
usually triaged within a week.
